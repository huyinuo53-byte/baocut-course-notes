# 第3课分层样板

用来对比新旧两版的阅读效果：

- 旧版：[notes/lecture-03/课堂笔记.html](../../notes/lecture-03/课堂笔记.html)（2026-10-22 交付）
- 新版：[课堂笔记-分层样板.html](课堂笔记-分层样板.html)

| 文件 | 来源 |
|---|---|
| `notes.json` | 由 `build.py` 从旧版 HTML 逐字迁移生成，加上 `layer.json` 的地图和图解（notes v3） |
| `layer.json`、`visuals/*.svg` | 本次新增：课程地图和 17 张整理者图解，每张在 `refs` 写明依据的完整笔记条目 |
| `build.py` | 重建页面，并检查旧版的 198 个文本块和 18 幅原帧在新页面中一个不少 |

```sh
python3 examples/lecture-03-layered/build.py
```

边界：

- 完整笔记的内容没有改动，所以正文里的限制说明（“不能……”“未给出……”）仍是旧写法；新合同的 `caveat` 字段留给新生成的课程使用。
- 图解由制作者对照完整笔记自查，**还没有做独立的保真评测**；本地也没有本课原始转写，因此无法重新做召回题和 `source_ids` 覆盖校验。
- 第 9、17、20 节没有画图解：这几节没有比文字更适合用图表达的结构。
- 手机宽度下，图解里的次要文字（15–17px 设计尺寸）实际只有约 9px，需要点开放大才看得清；后续图解按 `layered-reading.md` 的 ≥20px 规范重画。
