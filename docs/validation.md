## 重现包校验

在原始解压目录中执行：

```sh
python3 tools/verify_package.py
python3 -B -m unittest discover -s skills/baocut-course-notes/scripts -p 'test_*.py' -v
python3 tools/run_demo.py --out build/check-demo
```

`PACKAGE-MANIFEST.json` 列出除自身外的全部发布文件 SHA-256 与大小。验证工具忽略演示输出 build/ 与 Python 缓存，但其他额外文件会报告。清单用于发现文件变更，不是数字签名或来源认证；修改任何发布文件后均应重新审查和生成清单。
