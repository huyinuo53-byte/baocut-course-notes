# 分层阅读与图解

页面分三层，读者从上往下按需深入：

| 层 | 内容 | 读者得到什么 |
|---|---|---|
| 课程地图 | 一张 SVG：本课的论证链或知识结构 + 摘要 | 30 秒知道这一课讲什么、各部分怎么连起来 |
| 知识点卡片 | 每节标题 + 一句话结论 + （值得画时）一张图解 | 不展开细节也能抓住每个知识点 |
| 完整笔记 | 默认收起，可逐节或一键全部展开 | 全部论证、数字、案例、原帧、外部资料与时间码 |

“图解速读”只是把完整笔记折叠起来，内容仍在页面里，页内搜索和打印都会展开。

## 图解借鉴 eli5，但不牺牲精度

eli5 的做法是：假设读者对主题一无所知，用大图、少字解释。这里沿用它的表达方式，同时加两条约束：

1. **只重组，不新增**。图里的每个元素（标签、数字、箭头的因果关系）都必须能在本节完整笔记里找到，并在 `visual.refs` 列出依据条目。完整笔记没有的东西，先补进完整笔记并绑定证据，再画。
2. **保留条件**。讲师说“约”“个人经验”“至少”，图上也写；条件分支不能画成必然结论。必要时在图角落加一行小字限制。

### 什么值得画

先问：这一节有没有一个结构，用图比用文字快？有就画，没有就不画，不凑数量。

| 内容结构 | 图形 |
|---|---|
| 两种方法/观点的对照 | 左右对比面板 |
| 条件 → 动作的判断 | 决策流程（菱形判断 + 分支） |
| 阈值、区间、尺度 | 数轴或标尺，标出关键刻度 |
| 先后步骤、案例经过 | 时间线 |
| 多个必要条件 | 漏斗或“全部满足才进入”的清单 |
| 比例、配置 | 按比例的条块 |
| 整课结构 | 课程地图：从左到右或从上到下的论证链 |

截图和讲义页是“证据图”，放在完整笔记里；图解是“解释图”，由你重新画。两者不互相替代。

### SVG 规范

- 一张图一个想法。正文文字 ≤ 30 个字，用短标签而不是句子。
- `viewBox` 宽 600；正文字号 ≥ 20，次要标注 ≥ 16，这样在手机 360px 宽时仍可读。高度按内容，通常 260–420。
- 颜色用页面同一套：底色透明或 `#faf8f3`，墨色 `#242b29`，弱化 `#636c66`，线 `#dcded4`，绿 `#244e3d`（顺势/做多/通过），锈红 `#974c35`（风险/做空/警示），浅绿 `#e6efe8`，浅红 `#f6e8e1`，紫 `#5a4775`（外部资料）。颜色不是唯一的信息通道，同时用文字或形状区分。
- 字体写 `font-family="PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif"`。不引用外部字体、图片或脚本。
- 写有意义的 `alt`：用一两句话说清图要表达的结论，供读屏和无法加载图片时使用。

## 一句话结论（takeaway）

忠实概括本节的关键判断，标为整理者提炼。不加入本节没有的条件或结论；讲师的个人经验仍写成个人经验。

## 课程地图

画出各节之间的关系，而不是把目录再列一遍：本课从什么问题出发、经过哪些步骤、落到什么结论或方法。地图上的每个节点对应一节或一组节，用节号标注，方便读者跳转。

## 检查

- 结构：`course_notes.py render` 检查覆盖、引用和 SVG 位置。
- 语义：每张图解和每句 takeaway 都进入 [保真评测](fidelity-eval.md) 的精度检查，100% 覆盖，不抽样。
- 视觉：在浏览器里看桌面和手机宽度，图中文字清晰、不溢出、不重叠；切换两种阅读模式、点击“依据第 N 条”能展开并定位。
